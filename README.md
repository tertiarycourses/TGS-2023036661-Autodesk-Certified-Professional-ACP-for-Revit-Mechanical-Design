## About the course

The course develops a complete mechanical-design evidence trail: model systems in a linked building, document them on sheets, create and validate MEP families, review analysis inputs and calculations, and coordinate issues across disciplines. The package is version v7.0.

## Learning outcomes

1. Build and calculate conceptual mechanical duct and piping systems with a Basis of Design.
2. Produce coordinated mechanical plans, sections, schedules, sheets and revisions.
3. Create and validate MEP family connectors, parameters and model accuracy.
4. Review spaces, zones, energy settings and calculated values against project criteria.
5. Manage linked-model coordination, clashes, standards and handover evidence.

## Topics covered

Mechanical modelling; drawing documentation; MEP families; energy and mechanical analysis; worksharing and collaboration.
